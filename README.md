# Synshare

Free, local-first document sharing for any device.

Share documents directly between phones, tablets, and computers. Synshare works entirely on your local network — no accounts, no cloud, no servers. Devices connect to each other directly and transfer files without anything leaving your network.

## Why Synshare

- **Local by default.** All transfers happen on your own network. Nothing is uploaded to a third-party server.
- **Works offline.** No internet connection needed — just devices on the same network.
- **Any device.** Flutter builds for Android, iOS, Linux, macOS, Windows, and web.
- **Private.** Your documents stay between your devices.

## Features

- Peer-to-peer document transfer between devices on a local network
- No accounts or registration
- No data leaves your network
- Cross-platform support via Flutter

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)

### Build and run

```bash
flutter pub get
flutter run
```

Pick the target device you want to run on, or build for a specific platform:

```bash
flutter build apk          # Android
flutter build ios           # iOS (macOS only)
flutter build linux         # Linux
flutter build macos         # macOS
flutter build windows       # Windows
flutter build web           # Web
```

### Run tests

```bash
flutter test
```

## Usage

1. Install Synshare on two or more devices on the same network.
2. Open the app on each device.
3. Send a document from one device; receive it on the other.
